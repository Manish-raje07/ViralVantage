## Features

### 1. 📊 Unified Metrics Dashboard

**What it does:**

- Displays key metrics across all connected social platforms
- Shows real-time engagement data
- Compares performance across different post formats

**Key Metrics Displayed:**

- **Total Reach** - Combined audience reach across platforms
- **Likes** - Total engagement in form of likes
- **Comments** - Audience discussion and interaction
- **Shares** - Content amplification metric
- **Engagement Rate** - Percentage of audience engaging with content

**Post Format Comparison:**
Analyzes performance by content type:

- **Reels/Videos** - Short-form video content
- **Carousels** - Multi-image/slide posts
- **Static Posts** - Single image or text posts

Shows metrics:

- Average engagement rate per format
- Number of posts per format
- Total reach generated by each format

**Platform Breakdown:**

- Visual representation of performance by platform (Instagram, Twitter, YouTube, etc.)
- Follower counts per platform
- Engagement rates by platform
- Side-by-side comparison

**Trends Tab:**

- Line charts showing engagement over time
- Reach trends
- Follower growth tracking
- Customizable time ranges (7, 30, 90 days)

**Top Performer Showcase:**

- Features your best-performing post
- Shows content type, text, and metrics
- Detailed engagement breakdown

### 2. 🤖 AI Query Interface

**What it does:**
Ask natural language questions about your social media performance, and the AI provides instant insights powered by Google Gemini.

**Example Questions:**

- "Which post had the highest engagement last month?"
- "Compare engagement rates between Reels and Carousel posts"
- "What's my peak posting time?"
- "Which platform drives the most sales?"
- "What's the average engagement rate across all platforms?"

**Features:**

- Real-time AI analysis
- Query history tracking
- Pre-defined example queries for guidance
- Natural language processing
- Context-aware responses

**How It Works:**

1. Type your question or click an example
2. AI analyzes your social media data
3. Generates a personalized response
4. Response saved in query history
5. Ask follow-up questions

## API Endpoints Used

```
GET /api/analytics?type=overview
  ↓ Returns: overall metrics, platforms, posts, trends

POST /api/ai-query
  ↓ Body: { query: "your question" }
  ↓ Returns: AI-powered insight response

GET /api/insights
  ↓ Returns: automated recommendations and insights

POST /api/reports
  ↓ Body: { reports: [...], format: "PDF|CSV|JSON", period: "..." }
  ↓ Returns: downloadable report file
```

## Troubleshooting

### Dashboard Shows No Data

- Verify API credentials in .env.local
- Ensure social media accounts are public
- Check API rate limits haven't been exceeded
- Wait a few moments for initial data load

### AI Queries Return Generic Responses

- Ensure MongoDB is connected and has data
- Check GOOGLE_GEMINI_API_KEY is valid
- Try more specific questions
- Verify posts are in the database

### Export Reports Fail

- Check file system permissions
- Verify MongoDB has sufficient data
- Ensure report selections are made
- Try different export format
